FreeShow Admin — Design Changes

Applied 2026-04-22 · feature/freeshow-admin worktree · impeccable skill

What changed and why

The original UI was functional but had zero brand identity — achromatic palette, generic card patterns, and native alert() dialogs. This pass aligned the UI to the design context: Blunt. Poppy. Self-aware. Inspired by Trainline's direct, colorful, unafraid aesthetic.

Design principles applied

Get out of the way
Dashboard removed the "hero metric" stat-card pattern. Content counts are now a single subtitle line. Less ceremony, same information.
Earn the color
The new teal-green primary (oklch(0.46 0.17 160)) only appears on active nav items, primary buttons, links, and interactive focus rings. Nowhere decorative.
Speak plainly
Copy cleaned up: "History Timeline" → "History", "Import FreeShow Files" → "Import", "Save & Create" kept (descriptive). Empty states now have personality without being cutesy.
Small corners, big power
Sonner toast replaces all alert() calls. Errors surface immediately without blocking. Success toasts confirm saves without inline state clutter.
Auth lives separately
The nav sidebar now hides on /auth/* routes. The main layout centers the auth view. A small brand mark identifies the app without redundant nav chrome.

Color palette

Migrated from achromatic (0 chroma) to teal-tinted OKLCH. All neutrals tinted toward hue 160. Chroma reduces at extremes to avoid garish light/dark tones.

Typography

Replaced system default stack with Barlow Condensed (headings) + Barlow (body). Neither appears on the impeccable ban list. Barlow Condensed is blunt and functional — deliberately non-precious, slightly military without being cold.

  • Barlow Condensed 700 — page headings (h1, h2, h3, h4 via CSS base layer)
  • Barlow 400/500 — body text, labels, inputs
  • Fonts loaded via Google Fonts preconnect in __root.tsx head config
  • Fixed rem scale for app UI (no fluid clamp — correct for dashboards)
  • All h1 headings at text-3xl font-bold tracking-tight

Auth route isolation

Auth pages now render without the nav sidebar. Two changes coordinated:

Before
// __root.tsx const isPublicShare = pathname.startsWith("/s/") // Only /s/* routes hidden nav // nav-sidebar.tsx if (pathname.startsWith("/s/")) return null // Auth pages got full sidebar
After
// __root.tsx const isAuthRoute = pathname.startsWith("/auth/") // Auth routes: centered flex main // nav-sidebar.tsx if (pathname.startsWith("/s/") || pathname.startsWith("/auth/")) return null // Clean fullscreen auth experience
